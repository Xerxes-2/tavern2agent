# 叙事节拍参考（GM 可选）

GM agent 不知道「这一轮该不该升级冲突 / 该不该塞反转」时的判断尺。标准方案的 `gm.md` 可以引用本文档；轻量方案不需要。

## 每场戏必过的两关

### 价值转换
每个场景结束时必须有某种价值翻面：希望→绝望、信任→背叛、亲近→疏离、安全→危险。开始和结束情感状态相同的场景就是多余戏。
**RP 中的应用**：每轮回复至少推动一个微小的价值变化，哪怕只是「敌意 → 半敌意」。

### 麦基场景三问
1. 这场戏里**什么价值**变化了？
2. 从**什么状态**变成了**什么状态**？
3. 没有变化——那这场戏为什么存在？

写完一段叙事后自查这三问，过不了就重写或合并到下一段。

## 三大节奏引擎

### 信息不对称
谁知道得多，决定戏的类型：

| 配置 | 效果 | 适用 |
|------|------|------|
| 观众 > 角色 | 戏剧性反讽（炸弹在桌下） | 紧张悬疑 |
| 角色 > 观众 | 神秘叙事（这人到底想干嘛） | 好奇驱动 |
| 双方都不全知 | 悬念叙事 | 不确定性 |

**螺旋揭示**：信息分层放出，每层既回答旧问题又抛出新问题。一次倒完真相 = 戏死。

### 打破预期
**熟悉 + 新颖** 是最佳配比。
- 用熟悉原型给安全感，再用意外转折打破惯性
- 陌生化：经典模式放进意想不到的背景
- 类型混合：两种类型元素碰撞
- 反类型角色：英雄有致命缺陷、反派有可同情动机

### 情感波浪线
情感推高 → 拉低 → 再推高，振幅渐进增大，高潮处最大。冯内古特发现「先跌后升」的形状收益最高。
**RP 中的应用**：连续 3 轮以上情感平稳就该制造扰动；高潮后留 1-2 轮余韵再起新冲突。

## 七种基本剧情模式（布克）

战胜怪物 / 从穷到富 / 追寻 / 远航与回归 / 喜剧 / 悲剧 / 重生。
五阶段节奏通用：**期待 → 梦想 → 挫折 → 噩梦 → 奇迹（或毁灭）**。

判断当前剧情走在哪个模式、哪个阶段，下一步该往哪推。

## 12 原型（皮尔逊，速查）

**自我层（准备）**：无辜者 / 孤儿 / 战士 / 关怀者
**灵魂层（旅程）**：探索者 / 毁灭者 / 爱人
**自性层（回归）**：统治者 / 魔术师 / 智者 / 愚者

长篇里同一角色可依次扮演多个原型形成弧线（如「孤儿 → 战士 → 智者」）。

## 救猫咪 15 节拍（适用于规划完整故事线）

按总篇幅百分比：
开场画面 1% · 主题陈述 5% · 铺垫 1-10% · 催化剂 10% · 争论 10-20% · 进入第二幕 20% · B 故事 22% · 游戏时间 20-50% · 中点 50% · 坏人逼近 50-75% · 一无所有 75% · 灵魂黑夜 75-85% · 进入第三幕 85% · 结局 85-99% · 终场画面。

RP 一般不规划完整故事，但可以套用「中点」「一无所有」「灵魂黑夜」三个锚点，知道现在大概在哪儿。

## RP 简化版场景结构

每一段叙事循环按这五步推：

1. **触发**：明确的催化剂推动角色行动（NPC 一句话、环境变化、骰子结果）
2. **递进**：冲突逐步升级，赌注不断提高
3. **逆转**：每 3-5 轮一次意外转折
4. **高潮**：情感堆叠到顶点时释放
5. **余韵**：高潮后留 1-2 轮喘息，再起新循环

## 在 gm.md 里如何引用

不要把本文整个塞进 system prompt。在 `gm.md` 加一行：

```
叙事卡壳或拿不准节奏时，参考 references/storytelling.md 的「麦基场景三问」与「RP 简化版场景结构」自检。
```

agent 真有需要时会去 Read 这份文档；多数轮次它根本用不上。
