# 开局 setup

`first_mes` 在 agent 环境中，很多卡在叙事开始前**需要信息才能运转**——可能是用户角色定义、可能是难度/参数选择、可能两者都有。这些缺失信息由 agent 在开局时**主动向用户索要**。

---

## 分析：缺失信息清单

分析阶段扫描以下信号，汇总成一张清单：

| 检测信号 | 位置 | 含义 |
|----------|------|------|
| 世界书有 `{{user}}设定`/`{{user}}人设` 条目 | 世界书 entry comment | 卡片定义了用户角色模板，需提取已知字段，标记缺失字段 |
| `first_mes`/`description` 含 `{{user}}` 占位，但世界书无定义 | 卡片主字段 | 卡片期望用户有角色身份，但未定义——开局时需询问 |
| `first_mes` 末尾是问句/选项/配置引导 | `first_mes` | 卡片设计了开局选择（难度、路线、起始状态等），需用户决策 |
| world book 有描述"开局设置"的条目 | 世界书 | 同上 |
| `first_mes` 是纯叙事，无占位无问句 | — | 无缺失信息，开局直接叙事 |

---

## 产出：开局 skill

每个卡片迁移**必须产出** `skills/开局.md`。把 `first_mes` 改写成纯叙事散文（去掉 HTML/状态面板/`<thinking>` 等 ST 渲染标签），保留场景、人物、氛围、关键对白，内联到 skill 模板中作为叙事参考。下面是模板。

### 模板

```markdown
---
name: 开局
description: 开始/重新开始游戏。收集缺失信息后交付开场叙事。
---

# 开局

你是 {{角色名}} 世界的 GM。用户请求开始游戏。

## setup

在输出任何叙事之前，检查以下信息是否已就绪。缺失的信息**一次性列出**，附上默认值，让用户可以一键确认或只改想改的：

{{setup_checklist}}

**交互原则**：
- 所有缺失项在一轮内问完，不要逐项追问
- 每个缺失项给出合理的默认值（从卡片推断或通用默认）
- 告诉用户「直接说开始就用默认值，或者告诉我你想改的部分」
- 如果只有一个缺失项且容易回答，可以直接问；≥2 项必须合并为一轮

## 开场叙事参考

以下是原始开场叙事（改写自 `first_mes`，已剥离 HTML/状态面板/`<thinking>` 标签），**不要复述原文**，以此为参考展开场景：

{{opening_narrative}}

## 开场

所有信息集齐后，基于以上叙事参考展开场景，输出开场叙事。不要复述原文，让用户立即进入角色。
```

### `{{setup_checklist}}` 生成规则

从缺失信息清单逐条翻译：

| 清单条目 | checklist 文本（示例） |
|----------|---------------------|
| 无缺失 | 无需额外信息，直接进入开场。 |
| user 卡缺失 1-2 字段 | `用户角色需要以下信息，附默认值：[字段=默认值, ...]。直接说"开始"用默认，或告诉我要改的。` |
| user 卡完全缺失 | `请确认你的角色信息（默认值可直接用）：姓名="旅人"、性别=男、外貌="风尘仆仆的旅行者"、背景="收到一封神秘信件后来到此地"。直接说"开始"用默认，或告诉我你想改的。` |
| 开局选项 | `开局可选：[选项A/选项B]。默认 [选项A]，直接说"开始"用默认。` |
| 多条目混合 | 合并为一轮，每个条目附默认值。格式同上。 |

### 用户直接调用

用户可以随时对 agent 说「开局」来重新开始游戏。

---

## 平台集成

extension 负责 system prompt 注入 + 工具注册。首轮用户无输入时 agent 自动 call 开局 skill；用户也可以随时说「开局」手动触发。

流程：

```
用户说「开始」/ 首轮触发
        │
        ▼
  agent 读 skills/开局.md
        │
        ▼
  ┌─ setup 阶段 ─────────────────────────────┐
  │ 所有缺失项一次性列出，每项附默认值：        │
  │  · 姓名？默认"旅人"                       │
  │  · 开局场景？默认"酒馆大厅"               │
  │  · 难度？默认"普通"                       │
  │                                            │
  │ 「直接说'开始'用默认，或告诉我要改的」      │
  │                                            │
  │  用户回复 → 应用修改 + 默认值 → 继续       │
  └────────────────────────────────────────────┘
        │
        ▼
  agent 交付开场叙事
```
